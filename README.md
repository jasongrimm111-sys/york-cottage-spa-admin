# York Cottage Spa: admin portal

Sign-in page and app for running York Cottage Spa: bookings, calendar, therapists, rota, treatments, rooms, prices, vouchers, discount codes, emails and reports.

This repository only holds the app. All data lives in a private repository, reached with a GitHub key that is stored only in encrypted form (`vault.json`, unlocked by each user’s email and password). The demo button runs on made-up data in the browser.
